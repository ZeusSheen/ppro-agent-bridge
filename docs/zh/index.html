我为什么做这个

你是不是每天都要花很多时间剪视频？大部分时间都花在剪掉说错的段落、收紧停顿、把空镜放到对的位置上。这些都不是编辑上的决定，只是费时间。所以我做了一座桥，把这部分交给 AI。

01

精准

它按说话内容剪，然后回听每一处剪辑，再看几帧画面。字被剪掉半个、剪得太紧，都会先修好再往下走。

02

懂内容

它知道说了什么、时间线怎么排、画面上有什么。所以它在内容需要的地方下刀，而不只是哪里没声音就剪哪里。

03

空镜一次放好

素材和图形由它自己放上时间线，和剪辑一起完成，不用最后再单独做一遍。

三步开始

  1. 1

    下载

    点下载按钮，zip 文件会存到“下载”文件夹。右键点它，选「全部解压缩」。

  2. 2

    运行安装

    在解压出来的文件夹里，双击 1 Install Premiere Agent Bridge。会打开一个窗口检查你的电脑，帮你补齐缺的东西，并在桌面上放一个 Premiere Agent Bridge 快捷方式。

  3. 3

    启动，开始剪

    双击 Premiere Agent Bridge 快捷方式，再打开 Premiere Pro 和它的 Agent Bridge 面板（窗口 → UXP 增效工具 → Agent Bridge）。面板会告诉你该对 AI 助手说什么。

你需要准备什么

  • 一台 Windows 电脑。在 Windows 11 上测试过。暂不支持 Mac。
  • Premiere Pro 26.3 或更新版本。Beta 版也可以：已在 Premiere Pro 27.1 Beta 上实测。
  • 一个 AI 助手。Claude Code 或 Codex。
  • 两个免费工具。Python 3.10 或更新版本，以及 Adobe 的 UXP Developer Tool。安装窗口会告诉你怎么装。

安装窗口还会带你打开开发者模式：在 UXP Developer Tool 里打开一次，在 Premiere 的插件设置里再打开一次。可选：FFmpeg（缩放片段和回听检查要用）、faster-whisper（在你电脑上转录要用）。一步一步的说明见使用文档。

常见问题

免费吗？+

免费。它是开源软件，采用 MIT 许可证。你可以用、可以改、可以分享。

是 Adobe 做的吗？+

不是。这是一个独立项目。它用的是 Adobe 官方给 Premiere Pro 添加插件的方式。

会把我的项目弄乱吗？+

它动手之前会先检查，每一处改动都能用 Ctrl+Z 撤销。不过还是建议先在项目副本上试。

AI 怎么知道该剪哪里？+

它看三样东西：大家说了什么、你的时间线怎么排、剪出来实际听起来和看起来怎么样。它会回听音频，再看几张静帧。

Premiere 更新以后还能用吗？+

它建立在 UXP 上，这是 Adobe 现在给 Premiere Pro 添加插件的方式，而不是 Adobe 打算淘汰的旧 CEP 系统。新版 Premiere 改了什么的时候，安装窗口和桥会告诉你。

Mac 能用吗？+

暂时不行。现在只支持 Windows。

哪些 AI 助手能用？+

Claude Code 和 Codex。其他能在你电脑上运行命令的 AI 助手也能用。

面板显示“未连接”，怎么办？+

多数情况是桥的窗口关了：点面板上的「启动桥」，或者双击 Premiere Agent Bridge 快捷方式。还不行，就按使用文档里的排查步骤一步一步查。
