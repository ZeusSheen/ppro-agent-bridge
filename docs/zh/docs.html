使用文档

一步一步的说明，一篇讲一件事。每篇都有自己的链接，可以复制下来发给别人。

  • 怎么更新，怎么卸载更新：换掉桥的文件夹，再启动一次。卸载：删掉快捷方式、面板和文件夹。最后列出哪些东西会留下。
  • 面板显示“未连接”按顺序一项一项查。多数时候第一步就解决了。
  • 我们在你电脑上放了什么、放在哪、留多久桥在它自己的文件夹以外写下的所有东西：放在哪，什么时候消失。不用注册账号，没有追踪，这些东西桥一样都不上传。

怎么更新，怎么卸载

更新于 2026 年 11 月 6 日# 链接

更新：换掉桥的文件夹，再启动一次。卸载：删掉快捷方式、面板和文件夹。最后列出哪些东西会留下。

更新（从本网站下载的 zip）

  1. 从首页下载新的 zip。右键点它，选「全部解压缩」。

  2. 关掉桥的窗口，也就是标题为 Premiere Agent Bridge 的黑色窗口。

  3. 用新 zip 里的 ppro-agent-bridge 文件夹替换旧的。放在原来的位置，快捷方式就还能用。

  4. 双击 Premiere Agent Bridge 快捷方式（或者 zip 里的 2 Start Premiere Agent Bridge.bat）。它会自动把新面板加载进 Premiere。

  5. 检查：面板显示「已连接」；AI 助手检查桥的时候，会看到 "compatible": true。

整个文件夹一起更新：桥、面板和 AI 助手用的命令行必须是同一个版本。

换了存放位置？先删掉旧的 Premiere Agent Bridge 快捷方式，再双击 1 Install Premiere Agent Bridge.bat，打开「桌面快捷方式」重新建。桌面上已经有快捷方式时，安装窗口不会替换它。

配对令牌和请求日志还在原处（%USERPROFILE%\.ppro-agent-bridge），不用重新配对。

卸载

  1. 关掉桥的窗口，并在 Premiere 里关掉 Agent Bridge 面板。

  2. 如果设置过开机自动启动，先关掉：双击桥文件夹里的 setup_bridge.bat，关掉「开机自动启动」。或者删掉“启动”文件夹里的 Premiere Agent Bridge 快捷方式。

  3. 删掉桌面上和开始菜单里的 Premiere Agent Bridge 快捷方式。

  4. 在 UXP Developer Tool 里卸载（Unload）Agent Bridge 面板。如果你以前用 Add Plugin 手动加过它，也把它从列表里移除。

  5. 删掉 ppro-agent-bridge 文件夹。

  6. 愿意的话，把 %USERPROFILE%\.ppro-agent-bridge 文件夹也删掉。里面是配对令牌和请求日志（见我们在你电脑上放了什么）。

会留下来的，因为别的程序可能也要用：Python 和安装时装的 Python 组件、UXP Developer Tool、开发者模式（UXP Developer Tool 和 Premiere 里各一处），以及你自己装的 FFmpeg。没有别的程序用的话，按 Windows 平常的方法卸载即可。

AI 助手做出来的东西也会留下：它工作文件夹里的转录稿、导出的画面和剪辑计划；项目里的还原点序列（名字带“[restore 日期 时间]”）；以及从 0.7 起，在 FLAC、Opus、Vorbis 音乐旁边生成的 WAV。

如果面板是用 .ccx 安装包装的

  1. 关掉 Premiere。

  2. 用 Creative Cloud 的插件安装程序运行 /remove "Agent Bridge"。安装程序是 UnifiedPluginInstallerAgent.exe，位于 Common Files\Adobe\Adobe Desktop Common\RemoteComponents\UPI\UnifiedPluginInstallerAgent\。

  3. 如果是要更新：先按上面的方法移除，再用 /install 加新的 .ccx 文件安装，同样要关着 Premiere。直接装在旧版本上面不会重新加载。

.ccx 这条路还没有在真机上测试过。安装程序一次只运行一条命令：连续快速调用可能让它卡住，要重启 Creative Cloud 才恢复。

面板显示“未连接”

更新于 2026 年 11 月 6 日# 链接

按顺序一项一项查。多数时候第一步就解决了。

  1. 桥的窗口开着吗？面板的状态栏会显示下面这句（英文版 Premiere 里是 Disconnected — broker not running?）：

    未连接：桥没有在运行？

    点面板上的「启动桥」，或者双击 Premiere Agent Bridge 快捷方式；剪辑期间别关那个黑色的桥窗口。第一次点「启动桥」时，会问你是否允许面板启动它：选允许。面板大约 20 秒内连上：图标从变淡变成全彩，状态显示「已连接」。

  2. 桥的窗口一打开就关了，或者报了端口 8017 的错？说明别的程序已经占用了桥的端口。窗口里会写着类似这样的话：

    Cannot listen on 127.0.0.1:8017 (…). It is held by PID 1234 (python.exe). Is another broker running? Close that program, then start the broker again.

    通常是已经有一个桥窗口在运行了：用那个就行，或者把它关掉再重新启动。如果写的是别的程序，就关掉那个程序。（如果是 [::1]:8017，提示会长一点，意思一样。）桥故意不和别的程序共用端口：否则面板会连到那个程序上，而不是桥。

  3. AI 助手报 AUTH_FAILED？说明桥拒绝了它的配对令牌。提示是这样开头的：

    This broker (0.6.0) needs the pairing token and got no pairing token. …

    这说明 AI 助手用的桥和桥窗口里运行的不是同一份或同一个版本（0.5 以前的命令行根本不发令牌），或者是用另一个 Windows 用户运行的，或者它设置了桥那边没有的 PPRO_BRIDGE_TOKEN。让它用面板第一句话里写的那个桥文件夹，也就是桥窗口运行的那个文件夹。令牌本身千万不要粘贴、复制或发给别人。

  4. 面板过期了？AI 助手检查桥时，会看到 "compatible": false，以及类似这样的提示：

    Panel is ppro-agent-bridge 0.5.1, CLI is 0.6.0: reload the Agent Bridge panel in UXP Developer Tool.The panel is stale — its code differs from this checkout's plugin folder: Reload it in UXP Developer Tool.

    关掉桥的窗口再启动一次：它会自动把当前版本的面板加载进 Premiere。也可以在 UXP Developer Tool 里（要开着）点 Agent Bridge 面板的 Reload。如果面板显示卡住了（stuck），先保存项目，再重新加载。

  5. 面板因为已经有另一个面板连着而被拒绝？状态栏会显示：

    Refused: A live Agent Bridge panel is already connected — retrying in 30 s

    桥一次只能给一个面板用。另一个 Premiere 窗口（比如 Premiere Pro Beta）或者面板的第二个副本占着它。退出另一个 Premiere，或者在 UXP Developer Tool 里卸载那个面板：只关掉面板不够，关掉的面板仍然连着。之后这个面板会在 30 秒内接上，点「重新连接」可以马上接上。

  6. 还是连不上？双击桥文件夹里的 setup_bridge.bat：安装窗口会把 Python、Premiere、UXP Developer Tool 和开发者模式重新检查一遍。然后到 GitHub 上告诉我。从 0.7 起，AI 助手可以生成一份问题报告贴在那里，里面绝不会有你的令牌。

如果 AI 助手报 NO_BROKER（“Cannot reach broker at … Is broker.py running?”），说明桥窗口没在运行：从第 1 步开始。如果报 NO_PANEL（“No Premiere panel connected. Is Premiere open with the Agent Bridge panel loaded?”），说明桥在运行，但面板不在：在 Premiere 里用窗口 → UXP 增效工具 → Agent Bridge 打开它。菜单里没有的话，运行安装窗口：多半是没装 UXP Developer Tool，或者没开开发者模式。

关掉面板不会停掉桥，也不会断开连接：在 Premiere 27.1 上，面板关着也在运行，重新打开还是原来的样子。

我们在你电脑上放了什么、放在哪、留多久

更新于 2026 年 11 月 6 日# 链接

桥在它自己的文件夹以外写下的所有东西：放在哪，什么时候消失。不用注册账号，没有追踪，这些东西桥一样都不上传。

  1. 配对令牌：%USERPROFILE%\.ppro-agent-bridge\token。桥第一次启动时生成的一串随机密钥。AI 助手的命令行每次请求都会带上它，这样别的程序控制不了桥。它会一直留着，直到你删掉；删掉后，桥下次启动会再生成一个。千万不要给别人。

  2. 请求日志：%USERPROFILE%\.ppro-agent-bridge\audit\audit-YYYY-MM-DD.jsonl，每天一个文件。每个请求一行：要做什么（文件路径这类长内容会截短）、作用在哪个序列、结果如何、用了多久。保留 30 天：桥启动时会删掉更早的文件。AI 助手靠它了解之前发生了什么。想关掉的话，设置环境变量 PPRO_AUDIT_DIR=off。

  3. 快捷方式：桌面上和开始菜单里的 Premiere Agent Bridge；如果打开了「开机自动启动」，“启动”文件夹里也有一个。它们会一直留着，直到你删掉；安装窗口里也可以再关掉开机自动启动。

  4. Premiere 里的面板：每次 Premiere 启动，桥都会通过 UXP Developer Tool 把它加载进去，和在那里点 Load 一样。UXP Developer Tool 和开发者模式会一直装着、开着。如果面板是用 .ccx 装的，Creative Cloud 会一直保留它，直到你移除（见怎么卸载）。

  5. 音乐的 WAV 副本（从 0.7 起）：Premiere 读不了 FLAC、Opus、Vorbis。导入这类文件时，会在它旁边写一个 48 kHz 24 位的 WAV（song.wav；如果那里已经有一个不同的 song.wav，就叫 song (48k).wav），然后导入这个 WAV。旁边已经有同样长度的 WAV 时直接复用。它会留着，因为你的项目在用它。

  6. 渲染留下的临时文件：Premiere 渲染 H.264 视频时，会先在目标文件旁边写临时文件（文件名后面加一串长代码，扩展名是 .m4v 和 .aac），最后才写出 .mp4。这些是 Premiere 自己的文件，桥不会删它们。如果渲染中途停了，可以手动删掉。

  7. 更新检查的设置（从 0.7 起）：%USERPROFILE%\.ppro-agent-bridge\settings.json。桥每天向 GitHub 查一次最新版本号，好让面板在有新版本时告诉你。它不发送任何账号、机器或用户标识。这项检查默认打开，可以关掉；你选择跳过的版本也记在这个文件里。

  8. AI 助手做出来的东西：转录稿、导出的画面、剪辑计划和回听检查用的音频，都放在你打开 Claude Code 或 Codex 的那个文件夹里。项目里的还原点是额外的序列，名字是“… [restore YYYY-MM-DD HH:MM]”；每个序列保留最新的 5 个。不需要了就删掉。

  9. Whisper 模型（如果你在本机转录）：第一次运行时会下载模型文件。faster-whisper 把它们放在自己的下载目录里，位置不是桥决定的。

Python 和它的组件、UXP Developer Tool、FFmpeg 都是你自己装的程序，卸载之前会一直在。怎么移除桥本身：见怎么卸载。
